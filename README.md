Neon Harbor is an original open-world crime game set in the sun-soaked coastal city of Port Solano: steal cars, outrun the police across a wanted system, and run a three-job story for fixer Dario Kess as ex-getaway driver Mara Voss. It plays entirely offline in a desktop browser from static files, with traffic, pedestrians, combat, a live minimap, synthesized sound and music, and save games in your browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

To build the entry dossier (what make.fun grades):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
